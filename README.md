# Cadence SideStore releases

Cadence is a personal iOS player for local music.

## Install or update

1. Add this SideStore source on your iPhone:
   https://github.com/ElicoftZ/cadence-sidestore/releases/latest/download/cadence-source.json
2. Install Cadence from SideStore. Later releases appear in SideStore at the same source URL.

The latest IPA is also available at:
https://github.com/ElicoftZ/cadence-sidestore/releases/latest/download/Cadence0.4.0.ipa

The IPA includes HeSuVi HRIR filters, source notes, and the GPL-2.0 license text. This repository contains installable artifacts only; Cadence source stays in the private source repository.
